# Planify: Plataforma de Gestión Financiera Personal

## Introducción

Planify es una aplicación orientada a la **gestión de finanzas personales**, cuyo propósito principal es ayudar a los usuarios a llevar un control estructurado de sus ingresos, egresos y metas financieras. La herramienta busca ofrecer un entorno accesible y seguro para el manejo de información económica, facilitando la toma de decisiones en torno a los recursos disponibles.

## Estructura del Repositorio

El proyecto se organiza en las siguientes carpetas principales, las cuales contienen toda la documentación, el código y los artefactos necesarios para el desarrollo de Planify:

| Carpeta                           | Descripción                                                                                                                                                                           |
| :-------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `Implementacion`                  | Contiene el **código fuente** de la aplicación Planify (principalmente JavaScript, CSS y HTML), que es el corazón funcional del proyecto.                                             |
| `Diccionarios y Especificaciones` | Contiene toda la **documentación técnica** del proyecto, incluyendo el diccionario de datos, modelos de negocio, y documentos de especificación detallada de requisitos.              |
| `Diagramas`                       | Incluye todos los **modelos visuales** del sistema, como diagramas UML (casos de uso, clases, secuencia) y cualquier otro diagrama de arquitectura que ilustre el diseño del sistema. |
| `ScriptsSQL`                      | Contiene los **scripts de SQL** necesarios para la creación de la base de datos, la estructura de las tablas (`DDL`) y, potencialmente, datos de prueba iniciales (`DML`).            |
| `Planes`                          | Contiene los **documentos de planificación** del proyecto, como cronogramas de trabajo, planes de gestión de riesgos, planes de pruebas, etc.                                         |
| `Otros Documentos`                | Contiene archivos de apoyo y documentación miscelánea que no se clasifica dentro de las carpetas anteriores.                                                                          |
